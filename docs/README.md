# Лендинг пилота «Бригада»

Статическая страница для набора бригад в пилот. Без npm, сборки, фреймворков и
внешних шрифтов: открывается как обычный `index.html` или раздаётся любым
статическим хостингом.

**Статус:** артефакт пилота, не публичный релиз. На странице стоит
`noindex, nofollow`; публиковать только после согласования с координатором.

## Что внутри

| файл | что делает |
|---|---|
| `index.html` | разметка, тексты по умолчанию на русском, два скриншота приложения |
| `styles.css` | молочный фон, charcoal, янтарный акцент, адаптив, состояния фокуса |
| `i18n.js` | полные словари RU / BE / EN (одинаковый набор ключей) |
| `app.js` | язык, URL, localStorage, метаданные, заявка, копирование и скачивание |
| `config.js` | контакты и ссылки организатора; по умолчанию пусто |
| `assets/mark.svg` | знак «Бригада» |
| `assets/favicon.svg` | иконка вкладки |
| `assets/shot-notes.png` | реальный скриншот экрана «Замечания» (G-01, демо-данные) |
| `assets/shot-task.png` | реальный скриншот задачи (D-01, демо-данные) |

## Как открыть

Из корня репозитория:

```bash
python3 -m http.server 8080 --directory landing
# http://127.0.0.1:8080/
```

Можно открыть и `landing/index.html` напрямую. В `file://` браузер может не
дать обновить URL через `history.replaceState`; язык и заявка при этом работают,
просто адрес не меняется.

## Скриншоты

В шапке два реальных снимка экрана приложения из
`work/pilot-ready/shots-current` (`G-01`, `D-01`), скопированных в
`assets/shot-notes.png` и `assets/shot-task.png`.

- На снимках демонстрационные данные и суммы в рублях — это демо-объект, не
  клиент. Подпись под телефоном: «Демонстрационные данные, русский интерфейс».
- Снимки не перерисовывать и не подписывать как «иллюстрацию»: это настоящий
  интерфейс. Если обновите APK и снимки — замените PNG, размер 1080×2400
  сохраняйте, чтобы вёрстка не поехала.

## Контакты организатора

Заполняется только `landing/config.js`:

```js
window.PILOT_CONFIG = {
  organizerName: "Имя организатора",
  email: "<адрес организатора>",
  telegram: "<@username или ссылка>",
  apkUrl: "<подтверждённая ссылка>"
};
```

- Пустая строка — функция скрыта. Никаких заглушек и выдуманных адресов.
- `email` — обычный адрес, без `mailto:`.
- `telegram` — `@username` или полная ссылка `https://t.me/...`.
- `apkUrl` — только подтверждённая ссылка от организатора. В магазине
  приложений приложения пока нет; не подставляйте сюда чужой APK.
- `config.js` публичный: пароли, токены и ключи здесь хранить нельзя.

Если контакта нет, страница честно говорит «контакт не подключён» и предлагает
скопировать или скачать заявку, чтобы передать её организатору. Форма никуда не
отправляется: нет `action`, `fetch` или скрытого endpoint. CTA на странице —
это заявка, а не готовый контакт; fallback остаётся, пока организатор не
заполнит `config.js`.

## Языки

- Переключатель в шапке и подвале: RU / BE / EN.
- URL: `?lang=be`, `?lang=en`; также поддерживаются `#be`, `#en`, `#lang=be`.
- Выбор запоминается в `localStorage` по ключу `brigada.pilot.lang`.
- При переключении обновляются `html[lang]`, `document.title`,
  `meta[name="description"]`, `og:title`, `og:description`, `og:locale`.
- Если языка нет в URL, localStorage и языке браузера — русский.

### Как править тексты

Все видимые строки лежат в `i18n.js` с одинаковыми ключами для трёх языков.
В HTML используется `data-i18n`, `data-i18n-aria-label`,
`data-i18n-placeholder`, `data-i18n-alt`. Если добавляете ключ — добавьте его во
все три словаря. Русский fallback есть, но он не должен быть основным для BE/EN.

Белорусский — литературный, не транслитерация русского. Термины держим
последовательно: «заяўка», «заўвага», «брыгадзір», «выпраўлена», «каштарыс»,
«прыёмка», «заказчык». Английский: «punch list» для замечаний, «client» для
заказчика.

### Что в текстах можно и нельзя

- Смета — это план; фактические часы ведутся отдельно. Не писать, что «в смете
  остаётся только сделанное».
- 1–3 объекта и 2–5 человек — профиль «так проще начать», а не тариф и не лимит.
  Выдуманного ограничения «больше 10 человек нельзя» нет.
- «Примерно неделя» — договорная гипотеза пилота, а не коммерческий срок.
- Офлайн: сохранение на устройстве и явное «Повторить» после возврата сети.
  Автоматическую досылку не обещаем, пока не подтверждена на живом прогоне.
- Технические ограничения — в FAQ, а не в каждом блоке лендинга.

## Заявка

Поля необязательные. Текст собирается в браузере и обновляется при вводе:

- «Скопировать заявку» — clipboard API, при отказе — скрытая textarea.
- «Скачать .txt» — Blob с BOM, имя `brigada-pilot-request-<lang>.txt`.
- Если в `config.js` есть email/Telegram, появляются кнопки «Открыть письмо»
  и «Открыть Telegram с текстом».
- Данные не уходят на сервер и не сохраняются в localStorage.

## Дизайн и доступность

- Палитра из приложения: `#F7F4EE`, `#202328`, `#EF650D`; для кнопок и мелкого
  текста используется более тёмный янтарный, чтобы был контраст.
- Системный шрифт, без Google Fonts и внешних CDN.
- Все интерактивные элементы — не меньше 44×44 px: кнопки языка, ссылки
  навигации, ссылки подвала, поля и кнопки заявки.
- Мобильная шапка компактная (56 px), но не прячет нужное: язык и логотип
  остаются, разделы — ссылками в подвале.
- Семантические секции, `skip-link`, `:focus-visible`, `aria-pressed` у языка,
  `aria-live` у статуса заявки, `details/summary` для FAQ.
- Есть `prefers-reduced-motion`.
- Адаптив: 1040 / 860 / 640 / 420 px; на мобильном карточки и отступы секций
  сжаты, горизонтального скролла нет на 360–390 px.

## Что не добавлять

- npm, сборку, фреймворки, service worker, аналитику, cookie-баннер.
- Внешние шрифты, стоковые фото, чужие логотипы.
- Тарифы, суммы в BYN, обещания экономии, отзывы, «юрсилу», ИИ-чудеса.
- Выдуманные адреса, телефоны, ссылки на App Store / Google Play / APK.
- Реальные персональные данные клиентов в примерах и документации.

## Чек-лист перед показом

1. `config.js` заполнен или сознательно оставлен пустым.
2. В трёх языках нет русских обрывков, кроме скриншотов приложения (они
   подписаны).
3. Проверены `?lang=be`, `?lang=en`, `#be`, перезагрузка — язык сохранился.
4. На телефоне 360–390 px ничего не вылезает по горизонтали.
5. Копирование и скачивание работают; в заявке нет чужих данных.
6. Нет фейковых ссылок и обещаний.
7. Координатор разрешил публикацию; `noindex` снимается только осознанно.

## Ограничения

- Без JavaScript не работает переключение языка и заявка; остаётся русский текст.
- Нет реального backend и приёма заявок.
- Скриншоты сделаны на демо-данных и на русском интерфейсе; белорусского и
  английского интерфейса приложения пока нет.
- BE/EN переводы нужно вычитать носителю.
- Страница не проверялась сборкой/линтером: это статика без сборки.
